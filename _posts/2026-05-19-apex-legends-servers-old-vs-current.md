I made this post to document how Apex Legends servers have changed over time. It's a short one, so I won't yap.

## Old Servers

Apex ditched their old servers and moved to Amazon data centers.

Here's a screenshot of how the old server browser looked:

![Apex Legends Old Servers](/assets/apex-legends/apex-legends-old-servers.png){: .w-75 .shadow .rounded-10 }

## Current Servers

Apex now runs on Amazon data centers across several regions. Here's the current server list:

| Region         | Location  |
| -------------- | --------- |
| ap-southeast-1 | Singapore |
| ap-southeast-2 | Sydney    |
| ap-northeast-1 | Tokyo     |
| ap-east-1      | Hong Kong |
| us-east-1      | Ashburn   |
| us-east-2      | Ohio      |
| us-west-2      | Oregon    |
| eu-central-1   | Frankfurt |
| sa-east-1      | São Paulo |
| me-south-1     | Bahrain   |

At the moment, the Bahrain server (me-south-1) is unavailable due to the ongoing situation over there. So if you're in the region, you'll be routed to one of the other servers.
