I decided to write this post after discovering that Free Media Heck Yeah (FMHY) had created a Fluxer server. I had joined their Discord server a long time ago, but I only recently found out about their Fluxer server through an announcement.

Fluxer is a free, open-source alternative to Discord. It's an app where people can chat, make video calls, and build online communities and more.

One of the main reasons I'm choosing Fluxer is that it's open source, meaning anyone can see how it works and contribute to improving it. It also has features planned for the future which I'm excited for.

The first feature is called **federation**. This means people using different Fluxer servers will be able to communicate with each other without needing to create a new account for every server. Think of it like email: someone using Gmail can still email someone using Outlook.

It means no single company has to control the entire platform. Communities can have more control over their own servers, rules, and data while still being connected to a larger network.

The second feature I'm excited about is **public forums that show up in Google searches**. Right now, a lot of useful conversations/solutions in apps like Discord are hidden from search engines. Fluxer plans to let communities make certain forum discussions public, so anyone searching Google can find helpful answers and information without having to join a server.

These features are still being developed, but they're a big part of why I'm interested in Fluxer. The goal is to give users more control over their communities and make useful information easier for everyone to find, even outside the app.
