Understanding the lecture class number is easy.

![Example of a lecture class number](/assets/uqu/lecture-class-number.png){: .w-100 .shadow .rounded-10 }
_Example of a lecture class number on the UQU student portal._

I'm going to use this class as an example. Looking at the القاعة (hall) part, you can see these numbers:

`41-0.012` and then a maps icon. But when you click it, it only shows the facility of your college. For example, mine is [College of Sciences](https://maps.app.goo.gl/yS1BaoGJY9e83BTw6), but it does not link to the exact lecture location.

So here is how to understand it:

**41-0.012**

## Building number: 41

The **41** is the building number of the location. For example:

![Building numbers around the campus](/assets/uqu/building-numbers.jpg){: .w-100 .shadow .rounded-10 }
_Building numbers around the campus._

These are the building numbers you see in this image, like 41 and 38.

## Floor number: X

Now the **41-X.012**:

The **X** is the floor number. 0 means you're on the first floor, and 1 means the next top floor.

## Classroom number: 012

Now the **41-0.XXX**:

This is the lecture classroom. You can find it easily as you move, depending on your number.

## The breakdown

| Part | Meaning |
| :--- | :--- |
| 41 | Building number |
| 0 | Floor number (0 = first floor, 1 = floor above) |
| 012 | Classroom number |
