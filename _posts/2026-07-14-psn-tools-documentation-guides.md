## How I Designed the Guide Images

I designed all the images in Canva using a simple method:

1. Copy the original image so there are two copies on the page.
2. Take the second copy and crop it to highlight a specific spot.
3. On the first (uncropped) image, set the brightness to -50 so it becomes much darker, making the cropped second image stand out.
4. Add highlight lines through the image using Stroke weight 4.
5. Round the corners to 41.
6. The highlight color is `#ff751f`.
